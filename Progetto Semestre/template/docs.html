GET /api/v1/models

Elenca i modelli attivi.

Windows (CMD) — tutto su una riga

curl http://localhost:5000/api/v1/models -H "Authorization: Bearer <key>"

Linux / macOS

curl http://localhost:5000/api/v1/models \
  -H "Authorization: Bearer <key>"

POST /api/v1/chat/completions

Invia una chat e riceve la risposta del modello. Registra token, costo e scala il saldo virtuale.

Windows (CMD) — tutto su una riga

curl -X POST http://localhost:5000/api/v1/chat/completions -H "Authorization: Bearer <key>" -H "Content-Type: application/json" -d "{\"model\": \"nvidia/nemotron-3-super-120b-a12b\", \"messages\": [{\"role\": \"user\", \"content\": \"Ciao!\"}]}"

Windows (PowerShell)

$body = '{"model": "nvidia/nemotron-3-super-120b-a12b", "messages": [{"role": "user", "content": "Ciao!"}]}'
Invoke-RestMethod -Uri http://localhost:5000/api/v1/chat/completions -Method Post `
  -Headers @{Authorization = "Bearer <key>"} -ContentType "application/json" -Body $body

Linux / macOS

curl http://localhost:5000/api/v1/chat/completions \
  -H "Authorization: Bearer <key>" \
  -H "Content-Type: application/json" \
  -d '{"model": "nvidia/nemotron-3-super-120b-a12b",
       "messages": [{"role": "user", "content": "Ciao!"}]}'

SDK OpenAI (Python)

from openai import OpenAI

client = OpenAI(
    api_key="<key>",
    base_url="http://localhost:5000/api/v1"
)

response = client.chat.completions.create(
    model="nvidia/nemotron-3-super-120b-a12b",
    messages=[{"role": "user", "content": "Spiegami Flask"}]
)

print(response.choices[0].message.content)

Streaming (consigliato)

Con stream=True i token arrivano subito e non si rischia il timeout su risposte lunghe. Consumi e costo vengono registrati a fine stream.

stream = client.chat.completions.create(
    model="nvidia/nemotron-3-super-120b-a12b",
    messages=[{"role": "user", "content": "Scrivi una poesia su Flask"}],
    stream=True
)

for chunk in stream:
    print(chunk.choices[0].delta.content or "", end="")

curl (Windows CMD)

curl -N -X POST http://localhost:5000/api/v1/chat/completions -H "Authorization: Bearer <key>" -H "Content-Type: application/json" -d "{\"model\": \"nvidia/nemotron-3-super-120b-a12b\", \"stream\": true, \"messages\": [{\"role\": \"user\", \"content\": \"Ciao!\"}]}"
